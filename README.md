# 🤖 MaxSchool - Sistema de Gestão Escolar para Oficinas

Sistema desenvolvido para a **Escola Municipal Arnaldo Antônio de Souza** (Dom Eliseu/PA) para gerenciar a enturmação de alunos em oficinas de Informática, Robótica, Futsal, Horta e Artes.

## 🚀 Funcionalidades
- **Painel Administrativo:** Dashboard com acesso seguro via login.
- **Cadastro de Alunos:** Gestão completa de estudantes por série e turno.
- **Matrícula Inteligente:** Sistema de matrícula em massa com filtros por turma.
- **Grade Semanal Dinâmica:** Visualização de alunos divididos por blocos de horários.
- **Relatórios:** Geração de listas de presença prontas para impressão.
- **Busca Avançada:** Implementação de busca instantânea com Select2.

## 🛠️ Tecnologias Utilizadas
- **PHP 8.x** (Lógica de back-end)
- **MySQL** (Banco de dados relacional)
- **Bootstrap 5** (Interface responsiva)
- **jQuery & Select2** (Experiência do usuário)

## 📦 Como instalar
1. Clone o repositório.
2. Importe o arquivo `database.sql` no seu PHPMyAdmin.
3. Configure a conexão no arquivo `includes/db.php`.
4. Acesse via `localhost/gestao_max`.
